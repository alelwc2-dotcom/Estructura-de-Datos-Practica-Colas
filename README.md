Proyecto modular en Java que implementa y evalúa las variantes de la estructura de datos lineal **Cola** (Estática Lineal, Estática Circular y Dinámica con Nodos Enlazados) para el Instituto Tecnológico Superior de Xalapa.

## Estructura del Proyecto
- **Estructuras_lineales/**: Contiene la clase `Nodo` y el paquete `COLA` con las implementaciones de `ColaEstatica`, `ColaEstaticaCircular` y `ColaDinamica`.
- **main_estatica/**: Contiene el `Main` independiente para probar la Cola Estática Lineal.
- **main_circular/**: Contiene el `Main` independiente para probar la Cola Estática Circular.
- **main_dinamica/**: Contiene el `Main` independiente para probar la Cola Dinámica.
